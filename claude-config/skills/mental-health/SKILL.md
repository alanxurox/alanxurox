# Mental Health Support

Cyclothymia-aware support protocol. Grounded in Alan's actual energy patterns — not generic wellness tips.

## When to Use

- Feeling overwhelmed, anxious, or stressed
- Cycling low — low energy, low motivation, brain fog
- Burned out or depleted after a high-output sprint
- Stuck on a problem and spiraling
- Need a reset before a hard conversation (1:1, review)
- Noticing a pattern that needs attention

**Not for:** Acute mental health crises — seek professional support.

## Energy Check-In (Start Here)

Before anything else, place yourself on the scale:

| State | Signals | Right Response |
|-------|---------|----------------|
| **High** | Flow, momentum, ideas firing | Protect the window — don't interrupt it |
| **Neutral** | Present, functional, not special | Normal work, light admin |
| **Low** | Fog, friction, everything takes longer | Reduce scope, no new commitments |
| **Depleted** | Can't start, overwhelmed by list | Stop. Rest is the work. |
| **Recovery** | Post-burst, need to recharge | Light tasks only or full off |

See `alan-context` for full cyclothymia pattern and planning implications.

## Grounding Protocol (Acute Overwhelm)

When anxiety or overwhelm spikes — do this before anything else:

**4-7-8 Breath:**
1. Inhale for 4 counts
2. Hold for 7 counts
3. Exhale for 8 counts
4. Repeat 3 times

**5-4-3-2-1 Grounding:**
- 5 things you can see
- 4 things you can touch
- 3 things you can hear
- 2 things you can smell
- 1 thing you can taste

After grounding: re-check energy state above. Don't make decisions during the spike.

## Cyclothymia-Aware Protocols

### Low Cycle Response
```
1. Acknowledge it — don't fight the cycle
2. Reduce the list to 1-2 must-dos maximum
3. Move complex/social tasks to a future high window
4. Protect sleep and food — basics first
5. Recovery is productive (enables next burst)
```

### Post-Burst Recovery
```
1. Expect a dip after high-output periods — it's normal
2. Don't fill the dip with more commitments
3. Light tasks: reading, cleanup, admin, easy reviews
4. Duration: typically 1-3 days before next cycle
```

### Spiral Interrupt (Stuck on Problem)
When work anxiety creates a thought loop:
```
1. Name the loop: "I'm spiraling about X"
2. Time-box it: set 15 min timer
3. If no progress: write down the blocker, close the tab
4. Move to a different task — return with fresh eyes
5. Ask for help (Claude, colleague) — stuck ≠ failing
```

## Work Hygiene Reminders

| Practice | Why It Matters |
|----------|---------------|
| **Breaks every 90 min** | Ultradian rhythm — focus cycles naturally |
| **Batch social/outreach** | High energy only — quality matters |
| **No commitments when depleted** | You'll over-promise and under-deliver |
| **End-of-day shutdown ritual** | Prevents work anxiety from bleeding into rest |
| **Acknowledge wins, however small** | Evidence offsets distorted self-assessment |

## End-of-Day Shutdown

Run this when closing work:

```
1. Write one thing that went well today
2. Write one thing to pick up tomorrow (single task, specific)
3. Close all work tabs
4. 5 min walk or stretch
5. Say out loud: "Work is done for today"
```

This creates a psychological boundary. Especially important during low cycles.
